02 / Architecture

How the system works

Everything reads from one source of truth, and nothing goes out without a human decision.

  1. INPUTSignals

    Mail, chat, meeting transcripts, Drive, Jira

  2. COREClaude Code

    Project memory, skills, playbooks

  3. CONNECTMCP + n8n

    Authenticated tools and workflows

  4. OUTPUTArtifacts

    Reports, plans, test cases, tickets, drafts

  5. GATEHuman review

    A named person approves what leaves
